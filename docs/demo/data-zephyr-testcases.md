# File: `demo/data/zephyr-testcases.json`

**What it is:** The stand-in Zephyr export: the DEMO-T* test cases with
names, objectives, steps (in the grammar the re-run engine understands),
priorities, business-critical flags, script paths, and whether each test is
approved for browser re-runs.

**Why it exists:** File-based Zephyr — the demo needs no Zephyr account.
Swap it for the real Zephyr adapter later.
